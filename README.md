# 🎮 NEXORA GAME

A 2D platformer game built with **Unity**, where players guide a playable character through level-based stages — collecting coins and keys, avoiding enemies, and progressing through checkpoints to complete each level.

---

## 📖 About

**NEXORA GAME** is a 2D side-scrolling platformer. Players control a character as they move through structured levels, collecting coins and keys, avoiding enemies, and reaching checkpoints to complete each stage.

🎨 Visual assets (backgrounds, character, and environment art) are sourced from the Unity Asset Store.

---

## ✨ Features

- 🏃 Playable character with movement, jumping, and environment interaction
- 🪙 Coins, score tracking, and collectible items
- 👾 Enemies with patrol movement that can damage the player
- ❤️ Health system with death and respawn handling
- 🗝️ Keys and locked doors for level progression
- 🚩 Checkpoints and level completion detection
- 📋 Main Menu, Pause Menu, and Game Over screens
- 🎬 Character and object animations, sound effects, and visual polish

## 🚀 Getting Started

### Prerequisites

- [Unity Hub](https://unity.com/download) installed
- A Unity Editor version compatible with this project (check `ProjectSettings/ProjectVersion.txt` in the repository for the exact version)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/NEXORA-GAME.git
   ```
2. Open **Unity Hub**
3. Click **Add project from disk** and select the cloned project folder
4. Open the project and allow Unity to import all assets
5. Open the main scene from the `Assets/Scenes` folder
6. Press ▶️ **Play** in the Unity Editor to run the game
